# 设计规范（K2「纸与印」）

kaili.dev 所有页面的视觉依据。新页面（文章页、文章列表、关于、管理端……）先读本文件，再动手；本文件没覆盖到的，先补进本文件再实现，不在单个页面里自创样式。

2026-10-25 起（D-169）：底色是暖白纸色，不叠加纸纹；公开页强调色是黛蓝，朱砂只留给印章、代码关键字和后台错误。D-168 的冷白试验只保留在开发环境的配色切换器里对照。HTML 参照稿仍是旧的宣纸色加纸纹，颜色以本文件 §2 为准。

- 依据的决策：D-106（个人站为主）、D-109（采用 K2）、D-110（首屏文字）、D-111（本文件与对比度修正）、D-112（响应式）、D-113 ~ D-122（第 8 轮：导航、Projects、书架、深色模式、正文字体、封面、OG 图）。
- 参照稿（`docs/kaili.dev-mocks/`）：首页 `k2-paper.html` / `k2-paper-en.html`；文章详情 `k2-article.html` / `k2-article-en.html`；Projects `k2-projects*.html`；书架 `k2-books*.html`；分享预览图 `k2-og.html`。共享样式在 `k2.css`（token、顶栏、页脚、通用组件）和 `k2-article.css`（长文排版），主题切换在 `k2-theme.js`。参照稿与本文件冲突时，以本文件为准，并回头修参照稿。

## 1. 设计原则

1. **像一本公开的个人笔记，不像作品集。** 页面讲「这个人在想什么、写什么、做什么」，不以简历、技能、项目展示为组织框架（D-106）。
2. **克制：靠排版和内容出个性，不靠装饰。** 不用渐变、大图横幅、动效、图标堆砌。每个页面最多一处「大声」的地方（首页是大字陈述）。
3. **「人」和「内容」分两种声音。** 标题、文章用宋体（内容的声音）；我自己说的话用霞鹜文楷（人的声音）。这是本风格最重要的区分，不要混用。
4. **公开页只留一个强调色：黛蓝。** 强调词、分类、悬停、焦点、进行中胶囊用黛蓝。朱砂只留给印章、代码关键字，以及后台的错误和危险操作。大面积的颜色只用于文字封面（黛蓝）和摘抄（墨）。

**两种模式下都不变的色块**：印章 `--seal` `#a63b26`、文字封面 `--cover` `#2c4a6b`。它们是「印」和「封面」，像实物一样不随灯光变色。摘抄卡片 `--quote-bg` 浅色是墨 `#1b1a17`，深色改为 `#0c0b0a` 并加 1px `--line` 内描边，否则会和深色页面融在一起。

深色块上的文字：封面上用 `#efe6d3`；摘抄卡片上正文 `#f3efe6`、出处 `#b7b1a4`；印章文字 `#f6ead8`。

### 深色模式（D-116）

- 三档：浅色 / 深色 / 跟随系统，默认跟随系统；手动选择记在浏览器本地，选「跟随系统」即清除记录。
- 切换控件在顶栏语言切换右侧，用一条 1px 竖线隔开，写法与语言切换相同（中文「浅 / 深 / 自动」，英文「Light / Dark / Auto」），当前项加粗。
- 主题必须在页面绘制前确定（`<head>` 里同步执行的脚本），不能先闪一下浅色。
- 深色是偏暖的近黑，不用纯黑；面板比底色明显高一档，代码块和卡片不靠描边也能分辨；朱砂和黛蓝提亮，色相不变。
- 分享预览图（§7）不跟随深色模式。

**对比度（WCAG，小字要求 ≥ 4.5:1）**，全部已验证：

| 组合 | 浅色 | 深色 |
|---|---|---|
| 墨 / 暖白 · 墨 / 面板 | 15.6 · 14.6 | 14.6 · 12.6 |
| 次墨 / 暖白 · 次墨 / 面板 | 10.2 · 9.5 | 10.5 · 9.0 |
| 黛蓝 / 暖白 · 黛蓝 / 面板 | 8.2 · 7.7 | 7.2 · 6.2 |
| 暖灰 / 暖白 · 暖灰 / 面板 | 6.3 · 5.9 | 6.7 · 5.7 |
| 朱砂 / 暖白 · 朱砂 / 面板 | 5.7 · 5.4 | 6.2 · 5.3 |
| 封面文字 / 黛蓝 | 7.4 | 同左 |
| 摘抄正文 · 出处 / 摘抄底 | 15.2 · 8.2 | 17.1 · 9.2 |
| 印章文字 / 朱砂 | 5.4 | 同左 |

「面板」一列覆盖代码块：代码高亮只用朱砂、黛蓝、暖灰和墨，所以代码块上的对比度就是这一列。

新增颜色或新的前景/背景组合时，先算对比度再用，结果补进上表。

**纸纹**：`--grain` 是一张空 SVG，页面和面板上没有噪点；暖白纸色本身承担「纸」的感觉。`/_design` 里的纸纹对照项在这张空图上没有纹理。

## 3. 字体

### 中文页面

| 角色 | Token | 字体 | 字重 | 用在哪里 |
|---|---|---|---|---|
| 标题 | `--title` | 思源宋体（Noto Serif SC） | 900（大标题、板块标题）／ 600（列表标题、小标签） | 大字陈述、板块标题、文章标题、「此刻」行标签 |
| 正文 | `--body` | 思源宋体（Noto Serif SC） | 400 ／ 600（加粗） | 文章正文（D-117） |
| 人的声音 | `--hand` | 霞鹜文楷（LXGW WenKai，简体） | 400 | 自我介绍、「此刻」内容、项目的一句话、摘抄。**只用于「我说的话」** |
| 界面 | `--ui` | Inter + 苹方 | 400 / 500 / 600 | 正文默认、导航、摘要、按钮、表单 |
| 数字 | `--num` | IBM Plex Mono | 400 / 500 | 日期、编号、阅读时长、网址 |
| 西文点缀 | `--latin` | Cormorant Garamond | 500 | 站名「Kai Li」、印章字母、项目名、书名 |

### 字体加载（D-131）

| 规则 | 说明 |
|---|---|
| 全部自托管 | 不请求 Google Fonts、jsDelivr 等第三方字体服务，字体文件和网站同域 |
| 思源宋体只要 400 / 600 / 900 | 按字符范围（unicode-range）切片，浏览器只下载页面用到的那几片；文章正文来自数据库，内容不固定，所以不能做静态子集 |
| 霞鹜文楷做子集 | 「我说的话」都写在代码仓库文件里（D-101 / D-107），构建时统计用到的字，只保留这些字；检查脚本保证不缺字 |
| 后备字体栈 | 每个 token 都写好后备字体，网络字体没下载完或失败时用系统字体显示，不出现空白（`font-display: swap`）。`--hand` 的后备依次是 Kaiti SC、STKaiti、KaiTi |
| 验收 | 用浏览器网络节流（慢速 3G）测一次首屏，记录首屏和字体加载时间 |

### 英文页面

英文页面只覆盖两个 token，其余同中文：

| 角色 | Token | 字体 | 说明 |
| 标题 | `--title` | Source Serif 4（800） | 思源宋体的同族西文，气质一致。大字用 800，不用 900 |
| 正文 | `--body` | Source Serif 4（400） | 文章正文 |
| 人的声音 | `--hand` | Source Serif 4（400） | 与英文标题、正文同族的常规体，靠「衬线 vs 无衬线」区分人和界面 |

英文页面另外的规则：
- 摘抄用斜体（`font-style: italic`）；**中文永远不用斜体**（中文没有真斜体，浏览器只会把字形歪斜）。
- 强调词仍用「黛蓝色 + 下划线」，不用斜体（避免与参考站的手法相同）。
- 「此刻」的行标签（Reading / Writing / Building / Practising）用 `--ui` 600，因为英文单词比中文两字标签长。

### 响应式字号补充（D-140）

以下覆盖默认字号阶梯，未列项保持默认；行高为无单位的字号倍数。

| 用途 | 宽度 | 中文：字号 / 行高 | 英文：字号 / 行高 |
|---|---|---|---|
| 首屏大字 | 640px < 宽度 ≤ 960px | 3.2rem / 1.16 | 3rem / 1.1 |
| 首屏大字 | ≤640px | 2.35rem / 1.22 | 2.25rem / 1.22 |
| 首页自我介绍正文 | ≤640px | 1.08rem / 1.8 | 1.08rem / 1.7 |
| 首页首篇文章标题 | ≤640px | 1.18rem / 1.35 | 1.18rem / 1.35 |
| 子页面可选介绍 | ≤640px | 1.02rem / 1.8 | 1.08rem / 1.7 |

- 手机英文子页面介绍保留参照稿实际生效的 1.08rem，不统一缩到 1.02rem。两语言字号不同，但行高均为 29.376px（根字号 16px 时）；这是批准后的显式规则，不依赖 CSS 选择器优先级偶然保住英文字号。
- 自我介绍里的姓名 `.intro .name` 保留 1.6rem、字重 500，并继承各语言无单位行高；第一行可因姓名较大而更高，不能把所有子元素强制为正文字号。
- 首页首篇标题沿用中文 900 / 英文 800 字重；不与普通列表标题、文章详情标题混用。手机规则只覆盖对应元素字号，未列的字重、字距和其他规则不变。
- 沿用参照稿实际排版，不改参照文件。批准不等于 T2.5 组件验收；迁移后仍检查中英三宽浅深及内容变化后的换行。


### 长文排版（文章详情页；后台编辑器预览区沿用）

参照稿：`k2-article.html` / `k2-article-en.html`，样式在 `k2-article.css` 的 `.prose`。

| 元素 | 规则 |
|---|---|
| 行宽 | 正文栏最大 41rem：中文约 38 字一行，英文约 70 字符一行 |
| 段落 | 段间距 1.15em，不首行缩进 |
| 二级标题 | 宋体 900，1.42rem，上距 2.2em；进目录 |
| 三级标题 | 宋体 600，1.15rem，上距 1.8em；进目录，缩进一级 |
| 四级及以下 | 不使用；写作时最多到三级 |
| 加粗 | 600，不变色。中文不用斜体（§3） |
| 正文链接 | 黛蓝 + 细下划线（45% 透明度），悬停仍是黛蓝，只把下划线改成不透明。这是全站「链接默认不加下划线」的唯一例外：正文里的链接只靠颜色区分不够 |
| 引用 | 别人的话：宋体次墨，左侧 3px `--line` 竖线。不用文楷（文楷只给「我说的话」），不加引号装饰 |
| 列表 | 项目符号和编号用暖灰；有序列表编号用等宽字 |
| 行内代码 | 等宽 0.86em，面板底，圆角 3px |
| 代码块 | 面板底 + 1px 线框，圆角 4px，无纸纹；等宽 0.84rem / 行高 1.65；右上角暖灰小字标语言；过长只在块内横向滚动 |
| 代码高亮 | 只用已有颜色：关键字朱砂，字符串和数字黛蓝，注释暖灰（不斜体），其余是墨。不引入新颜色，深色模式自动跟随 token |
| 图片 | 正文栏满宽，1px 线框，圆角 3px，不加阴影；图注用 `--ui` 0.84rem 暖灰 |
| 表格 | `--ui` 0.92rem；表头 600 + 1px 次墨线（`--ink-2`），行间 1px `--line`；数字列用等宽字；过宽时块内横向滚动 |
| 分隔线 | 居中一段 96px 宽的 1px `--line` |

页面结构：

- **页头**横跨整页：「← 全部文章」→ 元信息行（黛蓝分类 · 日期 · 阅读时长）→ 文章标题 → 摘要（次墨）→ 2px 墨线。文章标题是这一页唯一「大声」的地方。
- **文章页不显示文字封面**：封面用在首页首篇和分享预览图，文章页本身靠标题。
- **目录**：桌面端在右栏（13rem 宽），吸顶，当前小节墨色 + 左侧 2px 黛蓝线（只变色，不滚动动画）。≤ 960px 移到页头下方，面板底的折叠块「目录 · 展开」，默认折叠。文章没有二级标题时不显示目录。
- **文末**：标签（胶囊，链接到列表页的标签筛选）→ 1px 线 → 上一篇 / 下一篇两格。上一篇是更早发布的一篇，在左；下一篇是更晚发布的一篇，在右。缺一边时那一格留空，另一格位置不变（D-049）。手机上两格上下排。

## 4. 版面

- **内容宽度**：最大 1120px，左右留白 40px。文章页正文栏另有 41rem 上限（见「长文排版」）。
- **首页两栏**：左 1.25 : 右 1，栏间距 64px。首屏和首屏以下都用这个比例，保证左右对齐。
- **分区**：首屏与以下内容之间用一条 2px 墨色横线；区块内部的条目之间用 1px `--line`；书架这类轻量列表用 1px 点线。
- **顶栏**：高 76px，底部 1px `--line`，横线贯穿整个页面宽度（不随内容宽度截断）。导航只有「写作 / 书架」（Writing / Bookshelf，D-113 / D-135）；当前页面的导航项为墨色 500。
- **子页面页头**（Projects、书架，以后的文章列表沿用）：页面标题（宋体 900 2.4rem）+ 2px 墨线，与首页首屏以下的分区线呼应。标题下可以加一句「我说的话」（文楷次墨），**可选**：有真正想说的才写，没有就不写（D-133）。
- **页脚**：上边 1px `--line`，与内容同宽。

### 间距刻度（D-139，T2.4b v2）

- 实施依据为 [spacing-proposal-v2.md](spacing-proposal-v2.md) §3 的完整唯一映射；v1 仅留作历史提案。30 种正数 px 布局值收敛为 21 种，另有 0；所有原来的 18px 均保留，不为单个组件另加例外。
- 布局刻度（px）：0 / 2 / 4 / 6 / 8 / 10 / 12 / 16 / 18 / 20 / 24 / 28 / 32 / 36 / 40 / 44 / 48 / 56 / 60 / 64 / 72 / 88。2～12px 保留 2px 精度，12～48px 以 4px 步长为主但允许 18px。仅登记实际用到的刻度，不自动批准 Tailwind 默认的全部间距。
- 只映射 margin / padding / gap / inset / 四方向偏移及 scroll-margin / scroll-padding；em、auto、负值装饰偏移及行高、字距按映射保留。字号、尺寸、圆角、边框、transform 不做间距归并，响应式字号按 §3（D-140）执行。
- 刻度在组件内部复用，不新增全局 `--space-*`；采用 Tailwind utility 时核对实际计算值。接受目录层级差 14→12px、书架每本上下内边距合计 +4px 等差异；最终视觉验收仍看 T2.5 / T3.3 的中英三宽浅深截图，不把“单值最多 2px”当成视觉通过。


### 响应式

所有页面必须同时支持桌面、平板和手机，至少在 1440px、820px、390px 三个宽度下检查：页面不能出现横向滚动条，文字不能被截断或断在单词中间。

| 断点 | 宽度 | 规则 |
|---|---|---|
| 桌面 | > 960px | 默认版面：两栏 1.25 : 1，左右留白 40px |
| 平板 | ≤ 960px | 两栏改为单栏，栏间距 40px；左右留白 28px；首屏字号与行高见 §3「响应式字号补充」；首屏以下右栏（项目、书架、摘抄）排到文章之后，上方加一条 1px 分隔线；文章页目录移到页头下方并默认折叠；Projects 页缩略图 200px |
| 手机 | ≤ 640px | 左右留白 20px；顶栏分两行（第一行站名 + 语言切换 + 主题切换，第二行导航，导航过长时可横向滑动）；首屏大字允许自然换行，首屏、自我介绍、首页首篇标题与子页面介绍的字号和行高见 §3「响应式字号补充」；文字封面缩为 112px 宽，分类首字 3.4rem；文章列表的分类和日期移到摘要下方；元信息整体换行，但单项（日期、阅读时长）不拆开；项目缩略图 76px；文章标题中文 1.75rem、英文 1.85rem；上一篇 / 下一篇上下排；Projects 页缩略图在上、最大 320px；书架页读完年月和状态移到书名上方 |

写新页面时的做法：先按桌面写，再在同样两个断点下补规则；新组件如果在手机上需要特殊处理，把规则补进上表。

## 5. 组件

## 6. 交互与动效

- 只允许：颜色过渡（约 0.15s），包括切换深浅模式时的底色和文字颜色。
- 不用：入场动画、滚动视差、悬停位移或放大（项目缩略图也不放大）、加载骨架屏动画。**后台同样适用**（D-129）：弹窗、下拉菜单、提示直接出现和消失，不淡入、不缩放。
- 键盘焦点必须可见：公开页用 2px 黛蓝描边（`outline`），后台仍用 2px 朱砂描边。不要去掉浏览器焦点样式而不补。

### 404（D-148）

- 复用子页面页头（§4）：中英文标题分别为「404 · 页面不存在」和「404 · Page not found」，下接 2px 墨线，不加插画、按钮或额外色值。
- 页头下用界面字体说明「这个地址没有可公开访问的页面。」/「There is no public page at this address.」，附普通文字链接「返回首页 →」/「Back to home →」。沿用 K2 顶栏、页脚及三宽浅深规则。
- `/en` 前缀使用英文，其余地址使用中文；真正返回 HTTP 404，不重定向、不显示任何草稿或缺失版本内容，也不声明 canonical / hreflang。404 的语言入口只链接到对应首页，不设置文章缺版本提示。

### 文章列表页（D-153）

- 页头：子页面页头（§4），标题「写作」/「Writing」，不加介绍。
- 一次性语言提示（D-036）：页头墨线下方 20px，`--ui` 0.9rem 次墨，`role="status"`；只在从文章切换语言且目标语言没有该文章时出现一次。
- 筛选：提示（若有）之下 24px，两行，行间 10px。每行左侧 `--ui` 0.9rem 暖灰标签「分类 / 标签」（Category / Tag），右侧「全部」（All）和各选项，项间 16px、换行行距 6px。选项为普通链接，默认暖灰，悬停黛蓝；当前项墨色 600，下方 1px 墨色下划线（`padding-bottom` 2px），带 `aria-current="page"`。点「全部」去掉该参数，保留另一项。≤640px 时标签在上、选项在下（间距 6px）。
- 列表：筛选之下 24px，`.post` 列表项（§5），按发布时间倒序。
- 空结果（D-132 / D-154）：筛选条件都合法但没有文章时出现，包括交集为空、只选一项且该项没有文章、以及当前语言还没有任何已发布文章。列表位置上下各 32px 内边距，底部 1px `--line`；`--ui` 次墨一句说明，按条件分别为「「{分类}」分类下没有带「{标签}」标签的文章。」「「{分类}」分类下还没有文章。」「还没有带「{标签}」标签的文章。」「还没有已发布的文章。」/「No articles in “{category}” are tagged “{tag}”.」「No articles in “{category}” yet.」「No articles are tagged “{tag}” yet.」「No articles published yet.」，下方 8px 暖灰链接「看全部文章 →」/「See all articles →」（去掉全部筛选）。
- 不用胶囊、下拉、底色框、图标或动画；颜色只用已有 token。

### 管理端（D-122 / D-129 / D-158 / D-163）

信息结构、路由、状态文字与反馈见 `admin-design-note.md`；本节只定视觉规则。D-163 起采用传统后台布局，取代 D-159 的列表 B 与编辑器 B。

- **字体与颜色**：表单、表格、按钮、导航一律 `--ui`；宋体和文楷只用于正文预览区（沿用「长文排版」）。不新增颜色；朱砂只表示错误或危险操作，成功用黛蓝；所有状态都配文字。不用动画（含弹窗、下拉、提示）。
- **框架**：左侧导航 200px，右边 1px `--line`，随视口高度固定：站名「kaili.dev 后台」600；导航「文章 / Idea / 分类与标签」，当前项面板底、墨色 600，其余暖灰；底部 0.84rem 暖灰「查看网站 ↗」与登录身份。内容区占满视口高度，自己滚动。≤960px 左侧导航改为顶部一行（站名、导航、「查看网站 ↗」与登录身份，不换行，放不下时整行横向滑动），下边 1px 线。
- **按钮**：沿用 `.ui-button`（1px `--line`、圆角 3px、面板底）；后台内边距 6px 12px、0.9rem、不换行。主要操作（发布、新建）为墨色描边 + 600 字重。危险操作（删除确认）为朱砂字 + 朱砂描边。禁用为暖灰字。表格里的行内操作用文字链接：普通黛蓝，删除朱砂。
- **列表页（文章 / Idea / 分类与标签）**：页标题 1.4rem 600 + 条数（暖灰）+ 右侧主要按钮；其下为搜索与筛选（或 Idea 快速输入、分类 tab）。这些固定不动，只有表格区域滚动；表头吸附在表格顶部（暖白底），表头 0.84rem 暖灰、下 1px 线；行间 1px 线，悬停整行面板底。分页栏固定在表格下方、上 1px 线：左侧暖灰「共 N 篇，显示第 a–b 篇」，右侧「上一页 / 页码 / 下一页」，页码为 1px 线框小按钮，当前页墨色描边 600，不可用的「上一页 / 下一页」暖灰。页数多时只显示首页、末页和当前页前后各一页，中间用「…」。每页 15 条。空结果在表格内居中一句暖灰说明。
- **状态颜色**：未创建 / 草稿暖灰；已发布黛蓝；已发布 · 有未发布修改为墨色 600。
- **编辑器**：顶部吸附一行（暖白底、下 1px 线）：「← 文章」暖灰、标题 600（过长省略）、未保存标记、反馈文字（成功黛蓝、失败朱砂）、「保存」「发布中文 / 发布英文」。下方两栏：左栏为语言 tab（当前 tab 墨色 600 + 2px 墨色下边线，未保存加「•」）及右端「对照另一种语言」勾选、标题、摘要、正文（等宽字体编辑；「编辑 / 分栏 / 预览」分段切换）；右栏 300px，依次为「发布」「共享信息」「参考资料」三个 1px 线框圆角 4px 的面板。勾选对照时，左栏再分两列，右列只读显示另一种语言（左边 1px 线），≤1100px 时排到下方。
- **弹窗**：Base UI Dialog / AlertDialog。暖白底、1px 线、圆角 4px、宽 min(440px, 视口 − 32px)；背景遮罩为暖白底 75% 透明叠加；直接出现和消失。标题 1.05rem 600，说明 ink-2。按钮右对齐，「取消」在前且默认获得焦点。
- **滚动条**：`scrollbar-width: thin`，`scrollbar-color: var(--dot) transparent`；WebKit 伪元素兜底（滑块 `--dot`，悬停 `--mute`，轨道透明）。
- **表单控件**：`.ui-input`；标签在控件上方，间距 6px；字段间 14～16px；错误说明在字段下方朱砂 0.86rem。
- **响应式**：≤960px 左右留白 20px；编辑器右栏收起，由顶部「文章设置」按钮展开（共享信息有错误时自动展开）；≤760px 表格改为一行一张卡片（每格前加暖灰字段名），表头在视觉上隐藏、对屏幕阅读器保留；Idea 快速输入区的编辑器和预览最高 160px，超出在区域内滚动，「保存」与「编辑 / 预览」同在输入框上方一行、右端对齐；Idea 表格内容列单行省略（D-164）；页面不得横向滚动。
