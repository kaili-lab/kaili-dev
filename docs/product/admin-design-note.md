# 后台信息结构设计说明（T5.3a）

2026-10-14 · Claude 起草（D-150），GPT-6.1 Sol 复核，选定按 D-147 / D-150。依据：D-020、D-034、D-037、D-038、D-045、D-053、D-066、D-068、D-071 ~ D-073、D-076、D-077、D-080、D-103、D-104、D-118、D-122、D-123、D-129、D-132、D-155、D-156、D-158、D-160；状态组合见 `article-state-cases.md`。

## 1. 页面与路由

| 路由 | 页面 | 说明 |
|---|---|---|
| `/admin` | — | 302 到 `/admin/posts` |
| `/admin/posts` | 文章列表 | 按发布时间倒序（D-104 / D-158 ①：取两种语言中较晚的 `publishedAt`；从未发布的排在最前，按最近保存时间倒序）；顶部「新建文章」 |
| `/admin/posts/new` | 新文章编辑器 | 首次保存成功后用 `replace` 换成 `/admin/posts/<id>`，不留新建页的历史记录 |
| `/admin/posts/<id>?lang=zh\|en` | 文章编辑器 | `lang` 缺省为 `zh`；切换 tab 只改 `lang`，不刷新页面 |
| `/admin/ideas` | Idea 页（D-080 临时布局） | 顶部快速输入区，下方列表（D-073 排序）；每条有「编辑」「用它写文章」「删除」 |
| `/admin/ideas/<id>` | Idea 编辑 | 同一 Markdown 编辑器组件的简单配置（D-071） |
| `/admin/taxonomy?tab=categories\|tags` | 分类与标签 | 两个 tab（D-037），缺省 `categories` |

后台导航（顶部一行，手机可横向滑动）：文章 / Idea / 分类与标签；右侧「查看网站 ↗」和登录身份。界面只有中文（D-121）。

## 2. 跳转

- 文章列表点一行 → 编辑器（该文章最近编辑的语言；没有记录时 `zh`）。
- Idea 列表「用它写文章」→ `/admin/posts/new?idea=<id>`，新草稿的参考资料预先挂上这条 Idea（D-103）。
- 编辑器参考资料里的 Idea →「打开」进 `/admin/ideas/<id>`（新标签页，避免离开编辑器丢失修改）。
- 编辑器分类选择旁「新建分类」→ 弹窗（不离开编辑器），创建后自动选中（D-118）。
- 编辑器「查看公开页」：该语言已发布时显示，链接 `/<lang>/writing/<slug>`，新标签页打开；未发布时不显示（D-039，不提供草稿预览链接）。

## 3. 16 种状态组合怎么显示

状态文字（D-155 ④ 推导）：

| 状态 | 文字 | 颜色 |
|---|---|---|
| 不存在 | 未创建 | 赭灰 |
| 草稿 | 草稿 | 赭灰 |
| 已发布 | 已发布 | 黛蓝 |
| 已发布有修改 | 已发布 · 有未发布修改 | 黛蓝；「有未发布修改」墨色 |

- **文章列表**：每行 = 标题（优先中文草稿标题，其次英文，都空时「（无标题）」）+ 两枚状态，固定顺序「中 · {状态}」「EN · {状态}」+ 分类 + 最近保存时间。16 种组合都由这两枚状态逐字表达，不合并成一个总状态。
- **编辑器**：语言 tab 写「中文 · {状态}」「English · {状态}」；当前 tab 下方一行写完整状态，已发布时附发布日期，如「已发布 2026-09-02 · 有未发布修改」。
- 颜色只用已有 token；朱砂只表示错误（D-129）。所有状态都有文字，不只靠颜色。
- 共享分类 / 标签改动（D-156 ①）：两种语言都已发布时，修改分类或标签并保存后，两枚状态都变为「已发布 · 有未发布修改」；之后只发布中文，中文变回「已发布」，英文仍是「有未发布修改」，直到英文也发布。列表与编辑器 tab 同时按此更新，不只更新当前 tab。

## 4. 保存与发布反馈

- 按钮：「保存」和「发布中文」/「发布英文」（随当前 tab），桌面在右栏顶部，手机固定在底部栏。
- 保存成功：按钮旁黛蓝文字「已保存 14:32」，`role="status"`；状态文字按第 3 节更新。
- 发布成功：黛蓝「中文版已发布 14:33」+「查看公开页 ↗」。发布同时保存当前语言内容和共享信息（D-155 ③），不需要先点保存。
- 校验失败（D-155）：按钮旁朱砂文字「未保存：请选择分类」或「未发布：缺少标题、摘要」，`role="alert"`；对应字段下方朱砂说明并获得焦点到第一个出错字段。失败时数据不变，编辑器内容保留。
- 进行中：按钮禁用并显示「保存中…」/「发布中…」，不用转圈动画（D-129）。
- 失败分两种（D-160 ②）：服务端明确拒绝时，保存为朱砂「保存失败：{原因}」，发布为朱砂「发布失败，公开内容未改变：{原因}」；网络错误或无响应时结果未知，朱砂「无法确认保存结果 / 无法确认发布结果，请刷新查看当前状态；编辑内容仍保留在编辑器中」。任何失败都不清除未保存标记，不自动重试。

## 5. 未保存修改

- 每个语言 tab 单独记录是否有未保存修改，tab 文字后加「•」和屏幕阅读器文字「有未保存修改」。
- 共享信息（slug、分类、标签）和参考资料关联的未保存修改单独标记：共享信息区标题后加「•」。
- 切换中 / EN tab 不提示，两边的未保存内容都留在页面里；保存或发布当前语言，提交当前语言内容和共享信息、参考资料关联（D-034），成功后清除这三者的标记；另一语言的未保存内容和标记保留。
- 离开编辑器（站内导航、关闭、刷新）时，任一语言、共享信息或参考资料有未保存修改就提示（浏览器 `beforeunload` + 站内路由拦截）；都没有修改不提示（D-038）。Idea 编辑同理（D-072）。

## 6. 编辑器结构

| 区域 | 桌面（> 960px） | 手机（≤ 640px），平板同手机但两侧留白 28px |
|---|---|---|
| 共享信息 | 左栏顶部：slug（任一语言发布后只读，D-155 ⑥）、分类单选 +「新建分类」、标签多选 | 同顺序，单栏 |
| 语言 tab | 左栏，共享信息之下 | 同 |
| 内容 | 标题、摘要（一句话）、正文（CodeMirror Markdown，D-045）；「编辑 / 预览」切换 | 同；预览为切换，不并排 |
| 状态与操作 | 右栏顶部：状态行、保存、发布、反馈 | 底部固定栏：保存、发布；状态行在 tab 下方 |
| 参考资料 | 右栏下方：已挂 Idea 列表（只读，可展开全文、打开、移除关联），「添加 Idea」从 Idea 列表选择；v1 只允许 Idea（D-103 / D-077） | 内容之后，默认折叠 |

预览区使用公开站的长文排版（宋体），表单和表格用 `--ui`（design §9 已定原则）。

## 7. 分类与标签（D-158）

- 两个 tab，表格列：中文名、英文名、slug、引用数、操作（编辑 / 删除）。表格上方「新建」，弹窗填写三项：中文名、英文名必填；slug 格式同文章 slug，只在同类内唯一。
- 引用数 = 以共享编辑值或任一语言公开快照引用它的文章数。引用数大于 0 时删除按钮禁用并写明「有 N 篇文章引用」；为 0 时可删除，先弹确认「删除分类「{名称}」？此操作不能撤销。」。
- 可以改名，改名立即显示在所有已发布文章和 OG 图上（D-160 ①），改名弹窗写明这一点；slug 被任一公开快照引用后只读。
- 标签由文章和资源共用（D-053），v1 引用数只统计文章；资源在 v1.1 加入。

## 7a. Idea（D-066、D-068、D-071 ~ D-073、D-076、D-080、D-103）

- 快速输入区和 Idea 编辑页都只有正文（无标题）和「保存」。内容去掉空白后为空时不能保存：按钮旁朱砂「请输入内容」，`role="alert"`，输入保留。保存成功黛蓝「已保存」，快速输入区清空并把新 Idea 放到列表顶部。
- 列表每条：正文摘要（前两行）、更新时间、「编辑」「用它写文章」「删除」。
- 删除：确认弹窗「永久删除这条 Idea？挂在文章里的参考资料关系也会删除，文章本身和已发布内容不受影响。此操作不能撤销。」确认后删除 Idea 及所有文章关联（D-068），留在 `/admin/ideas` 并显示「已删除」；在编辑页删除后返回 `/admin/ideas`。
- Idea 编辑有未保存修改时离开提示（D-072）。

## 8. 开发环境与生产环境入口（D-132）

- 开发环境：`/admin/*` 可进入，顶栏显示「Kai Li（开发环境假登录）」；登录检查写在服务端中间件和服务端函数入口，接口按真实登录设计，之后只替换实现。
- 生产构建：在接入 GitHub 登录前，`/admin/*` 和后台服务端函数都返回 404，响应中不含后台标记；网站地图不含后台路由。

## 9. 不做

动画（含弹窗、下拉、提示）；新颜色；自动保存；草稿预览链接；历史版本；定时发布；中英并排编辑。
