## 1. 批准内容与证据边界

- 30 种正数 px 布局值收敛为 21 种（20 种原值不变，90→88 新增一档），另有 0；10 个旧值、49 次出现改变。18px 的 8 次出现全部保留，不仅是“此刻”面板。
- 推荐修正版的决定性证据是当前英文 390px 首页：原样 v1 把面板内容区压窄 4px，Writing 从两行变三行；保留 18px 后仍为两行，面板较原稿高 10px。1440px 的桌面 26→24px 仍使 Practising 从两行变一行。文案或字体变化后须重测，不声称所有 UI 最优。
- 浏览器临时对照覆盖中英文首页、文章、书架，1440 / 820 / 390px × 浅深；未修改参照稿或组件。指标与截图在 `/tmp/kaili-spacing-ui-20261013/preserve18/`，推荐截图在 `/tmp/kaili-spacing-ui-20261013/english-mobile-recommendation.png`，原始 v1 对照在同级目录。该轮结果不是 T2.5 / T3.3 的最终验收。
- `preserve18/` 内截图后缀 `-v1` 与 metrics 的 `v1` 变体名代表“保留 18px”的候选，即本次 v2 映射；父目录同名变体才是原样 v1，不得混用。
- 接受目录层级差 14→12px、书架每本上下内边距合计 +4px 等其余变化。代码块、封面、Projects、OG 尚无最终视觉验收；移动端字号、性能及格线不包含在本次批准中。

## 2. 刻度及范围

**布局刻度（px）：0 / 2 / 4 / 6 / 8 / 10 / 12 / 16 / 18 / 20 / 24 / 28 / 32 / 36 / 40 / 44 / 48 / 56 / 60 / 64 / 72 / 88。**

- 2～12px 保留 2px 精度：书架两行之间 2px、作者/元信息 6px、胶囊内边距 8px、备注与正文之间 10px都能保留；不强行统一为 4px 倍数。
- 12～48px 以 4px 步长为主，但整档保留 18px（8 次），避免当前英文手机“此刻”文案多换一行；56 / 60 / 64 / 72 保留大区域留白和栏距，90→88。不是要求每个 4px 倍数都登记；只有本提案用到的值列入。
- 0 与 auto 原样：auto 是自动吸收剩余空间或居中，不是可取整的长度。负数 px 和 `-.08em` 都用于边缘对齐或装饰几何，原样保留，不作为普通 gap / padding 刻度。
- 长文与行内代码的 em 间距原样保留，维持跟随各元素字号变化的效果。例如 `1.15em` 是“该元素字号 × 1.15”，不能一律用 18px 代替；所有保留值也在 §3 唯一映射中，不是漏项。
- 行高、字距归排版，§3.3 全部不变；本次间距批准不补定字号。原有的四项字号缺口随后由 D-140 单独确认，现按 design.md §3「响应式字号补充」执行。
- 只处理清单列出的 margin / padding / gap / inset / 四方向偏移及 scroll-margin / scroll-padding。字体字号、宽高、圆角、边框、outline-offset、transform、图片裁切均不在范围。尤其印章宽 34px 不因“间距 34→32”变为 32px，正文最大 41rem、顶栏高 76px 和 OG 1200×630不变。
- 本表用 px 作为比较与迁移口径，不另引入 rem 换算或全局 `--space-*`。组件内部复用刻度值；若用 Tailwind 标准 utility，须确认实际计算值等于本表目标。实现方式留到 T2.5，不能把默认 Tailwind 全部间距当成本方案自动批准。
