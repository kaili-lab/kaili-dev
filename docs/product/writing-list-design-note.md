# 文章列表页设计说明（T4.1a）

2026-10-13 · Claude 起草（D-150）。用途：给 T4.1b 的方案变体划定边界；选定后写进 `design.md §9`（T4.1d）。

## 已定，方案之间不得不同

| 项 | 规则 | 依据 |
|---|---|---|
| 地址 | `/zh/writing`、`/en/writing`；筛选写在 query：`?category=<slug>&tag=<slug>` | D-037 |
| 页头 | 子页面页头：宋体 900 2.4rem「写作」/「Writing」+ 2px 墨线；文楷介绍可选 | design §4、D-133 |
| 列表项 | 沿用 `.post`：左宋体 600 标题 + 摘要，右朱砂分类 + 等宽日期；悬停标题变朱砂；≤640px 分类和日期移到摘要下方 | design §4 / §5 |
| 内容范围 | 只列当前语言已发布文章，按发布时间倒序；不分页、不按年份分组、不置顶 | D-050、D-104 |
| 筛选语义 | 一次最多一个分类、一个标签；两者都选取交集；选中项可单独取消 | D-037 |
| 非法参数 | 分类或标签不存在：去掉该参数并跳转，显示剩余条件的结果；两者合法但交集为空才显示空结果 | D-132 |
| SEO | canonical / hreflang 指向不带 query 的列表；筛选状态只留在地址栏 | D-143 |
| 语言提示 | 仅从文章页按语言按钮切换且目标语言没有该文章时显示一次，原文「这篇文章暂无中文版」/「This article isn't available in English.」；普通进入、刷新、新会话不显示 | D-036 |
| 禁止 | 无动画（含提示出现 / 消失）；无新颜色；朱砂只用于分类和悬停，不用于提示或空结果 | design §6、D-129 |
| 键盘 | 筛选项是普通链接，Tab 可达，焦点 2px 朱砂描边 | design §6 |

## 需要比较的三项

| 比较项 | 可变化范围 | 必须满足 |
|---|---|---|
| 筛选控件形态 | 文字链接行 / 状态胶囊（`.pill`）/ 原生下拉 `select` | 当前选中项不靠颜色单独区分（还要有字重或文字标记）；手机 390px 不横向溢出；不加图标 |
| 空结果 | 显示位置与文字；是否给「清除筛选」链接 | 说明当前条件（分类、标签名）；给出回到全部文章的链接；不用插画 |
| 提示位置 | 页头下方 / 列表正上方 / 筛选控件同一行 | 带 `role="status"`；墨色或次墨文字，不用朱砂；不遮挡列表 |

## 每个方案要截的状态

每个方案 × 1440 / 820 / 390 × 浅 / 深，各截四种状态：

1. 默认：`/zh/writing`（全部文章）
2. 已筛选：`/zh/writing?category=engineering&tag=typescript`
3. 空结果：分类、标签都合法但交集为空的夹具
4. 提示：从仅有英文的文章切到中文后的列表（`/zh/writing` + 一次性提示）

英文页面至少截默认和提示两种状态，确认英文提示原文和英文分类名。

## T4.2 前需一并定的规则（「需要先定的事」中的 query 异常）

按 D-147 / D-150 推荐方案，在 T4.2 开始前写入决策：

- 空值（`?category=`）当作没有该条件，跳转到去掉它的地址，与 D-132 的非法值处理一致。
- 同名参数出现多次时取第一个，跳转到只保留第一个的地址。
- slug 大小写不同（`?tag=TypeScript`）：按小写匹配；匹配成功跳转到小写地址，不匹配按 D-132 去掉。
- 其他无关参数（如 `utm_source`）原样保留，不影响结果，也不触发跳转。
